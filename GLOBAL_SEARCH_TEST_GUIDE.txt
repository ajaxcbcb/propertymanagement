WHAT TO LOOK FOR
═══════════════════════════════════════════════════════════════════════════

✓ WORKING CORRECTLY:
  • URL contains ?tenant=X or ?property=X
  • Filter indicator shows active filter
  • Table shows filtered results
  • You can see the filter in the filters panel
  • You can clear the filter

✗ NOT WORKING:
  • URL doesn't have query parameters
  • All records are shown (not filtered)
  • No filter indicator visible
  • Error messages appear


COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════

Issue 1: "No results found"
┌────────────────────────────────────────────────────────────────────────┐
│ This might be CORRECT if:                                              │
│ • The tenant has no tenancy agreements                                 │
│ • The property has no tenancy agreements                               │
│                                                                        │
│ Solution:                                                              │
│ • Check if the tenant/property has agreements in the database          │
│ • Try searching for a different tenant/property                        │
└────────────────────────────────────────────────────────────────────────┘

Issue 2: Filter not applying
┌────────────────────────────────────────────────────────────────────────┐
│ Solution:                                                              │
│ • Clear browser cache (Ctrl+Shift+Delete)                              │
│ • Hard refresh the page (Ctrl+F5)                                      │
│ • Check browser console for errors (F12)                               │
│ • Verify the URL has the query parameter                               │
└────────────────────────────────────────────────────────────────────────┘

Issue 3: Global search not showing results
┌────────────────────────────────────────────────────────────────────────┐
│ Solution:                                                              │
│ • Make sure you have tenants/properties in the database                │
│ • Run: php artisan db:seed (if needed)                                 │
│ • Check if search is enabled in the resources                          │
└────────────────────────────────────────────────────────────────────────┘
